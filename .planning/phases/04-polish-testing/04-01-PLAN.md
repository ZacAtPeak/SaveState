Modify WikiModalShell in three places to implement dismissal behavior per D-01 through D-04:

**CRITICAL: PopScope only controls back button/gesture, NOT tap-outside (barrier tap) dismissal.** Tap-outside dismissal is controlled by the `barrierDismissible` parameter on `showModalBottomSheet`. Both mechanisms are needed for complete dismissal protection.

**Known limitation:** `barrierDismissible` is evaluated once when `showModalBottomSheet` is called — it is a static parameter on the route. If the user opens the modal while NOT in create flow, then enters create flow, the barrier will remain dismissible until the modal is closed and reopened. This is acceptable for Phase 4; the primary use case (user taps + while already in create flow) is protected.

1. **Make barrierDismissible conditional on !provider.isCreating** in the static `show()` method (per D-02):
   Replace the entire `show()` method:
   ```dart
   static Future<void> show(
     BuildContext context, {
     VoidCallback? onClose,
     required WikiModalProvider provider,
     required List<WikiPage> pages,
   }) {
     return showModalBottomSheet(
       context: context,
       isScrollControlled: true,
       useSafeArea: true,
       barrierDismissible: !provider.isCreating,
       builder: (_) => ChangeNotifierProvider.value(
         value: provider,
         child: Consumer<WikiModalProvider>(
           builder: (context, modal, _) => WikiModalShell(onClose: onClose, provider: provider, pages: pages),
         ),
       ),
     ).then((_) {
       provider.cancelCreate();
     });
   }
   ```
   Key changes from current code:
   - Add `barrierDismissible: !provider.isCreating` — when isCreating is true, barrier taps are ignored (per D-02)
   - Wrap builder in `ChangeNotifierProvider.value` + `Consumer<WikiModalProvider>` so the modal shell receives the provider via Consumer (needed for PopScope below)
   - Keep the `.then((_) { provider.cancelCreate(); })` for post-dismissal cleanup (per D-01)

2. **Wrap Scaffold in PopScope for back-button protection** (inside the Consumer builder):
   Replace the current `return Scaffold(...)` inside the Consumer builder with:
   ```dart
   return PopScope(
     canPop: !modal.isCreating,
     child: Scaffold(
       // ... existing Scaffold content unchanged (appBar, body, etc.)
     ),
   );
   ```
   This blocks the Android back button when `modal.isCreating` is true. PopScope does NOT block tap-outside — that is handled by barrierDismissible above.

3. **Modify close button onPressed** to cancel create before popping (per D-01, D-03):
   Change the existing close button from:
   ```dart
   onPressed: () {
     Navigator.of(context).pop();
     widget.onClose?.call();
   },
   ```
   To:
   ```dart
   onPressed: () {
     widget.provider.cancelCreate();
     Navigator.of(context).pop();
     widget.onClose?.call();
   },
   ```

**Do NOT** modify the `reset()` method in WikiModalProvider — it is not called on normal close, so `_selectedPage` naturally persists across modal open/close cycles (per D-04).

**Summary of what each mechanism does:**
| Mechanism | Controls | Condition |
|-----------|----------|-----------|
| `barrierDismissible: !provider.isCreating` | Tap-outside (barrier tap) dismissal | Set at modal creation time |
| `PopScope(canPop: !modal.isCreating)` | Android back button/gesture | Dynamic via Consumer rebuild |
| Close button `cancelCreate()` + `Navigator.pop()` | Explicit close via X icon | Always cancels create |
| `.then((_) => cancelCreate())` | Post-dismissal cleanup | Runs on any dismissal path |

```dart
import 'package:test/test.dart';
import 'package:core/models/models.dart';
import 'package:core/wiki/wiki.dart';

WikiPage _page({String? id, required String title}) {
  return WikiPage(id: id ?? 'test-$title', title: title, pageType: WikiPageType.spell);
}

void main() {
  late WikiModalProvider provider;

  setUp(() {
    provider = WikiModalProvider();
  });

  group('selection', () {
    test('selectPage sets selectedPage', () {
      final page = _page(title: 'Fireball');
      provider.selectPage(page);
      expect(provider.selectedPage, equals(page));
    });

    test('selectPage with null clears selection', () {
      provider.selectPage(_page(title: 'Fireball'));
      provider.selectPage(null);
      expect(provider.selectedPage, isNull);
    });
  });

  group('create flow', () {
    test('startCreate sets isCreating to true', () {
      provider.startCreate();
      expect(provider.isCreating, isTrue);
    });

    test('cancelCreate resets isCreating and pendingType', () {
      provider.startCreate();
      provider.selectCreateType(WikiPageType.spell);
      provider.cancelCreate();
      expect(provider.isCreating, isFalse);
      expect(provider.pendingType, isNull);
    });

    test('cancelCreate is safe to call when not creating', () {
      expect(provider.isCreating, isFalse);
      provider.cancelCreate();
      expect(provider.isCreating, isFalse);
    });
  });

  group('dismissal behavior', () {
    test('cancelCreate preserves selectedPage', () {
      final page = _page(title: 'Fireball');
      provider.selectPage(page);
      provider.startCreate();
      provider.cancelCreate();
      expect(provider.selectedPage, equals(page));
    });

    test('reset clears selectedPage (explicit full reset)', () {
      final page = _page(title: 'Fireball');
      provider.selectPage(page);
      provider.reset();
      expect(provider.selectedPage, isNull);
    });
  });

  group('page management', () {
    test('addPage sets selectedPage to the new page', () {
      final page = _page(title: 'Fireball');
      provider.addPage(page);
      expect(provider.selectedPage, equals(page));
      expect(provider.pages, hasLength(1));
    });

    test('setPages replaces existing pages', () {
      final pageA = _page(id: 'a', title: 'Page A');
      final pageB = _page(id: 'b', title: 'Page B');
      provider.setPages([pageA]);
      provider.setPages([pageB]);
      expect(provider.pages, hasLength(1));
      expect(provider.pages.first.title, equals('Page B'));
    });
  });

  group('layout mode', () {
    test('setLayoutMode updates isTwoPanel', () {
      provider.setLayoutMode(true);
      expect(provider.isTwoPanel, isTrue);
      provider.setLayoutMode(false);
      expect(provider.isTwoPanel, isFalse);
    });
  });
}
```
