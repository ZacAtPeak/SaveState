## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Chip run spacing, dense inline separation |
| sm | 8px | Search input padding, compact row gaps |
| md | 16px | Default page/form/content padding |
| lg | 24px | Card internal vertical rhythm |
| xl | 32px | Major panel separation |
| 2xl | 48px | Tablet section breathing room |
| 3xl | 64px | Desktop-level content inset |

Exceptions: 44px minimum touch target for icon-only tap areas (close, back, add)

## Visual Hierarchy

Primary focal point is the create flow action and validation feedback region inside the modal content area. Secondary hierarchy is the searchable page list and selected detail pane; tertiary hierarchy is supporting metadata (tags/chips and helper copy).

Icon-only controls (close, back, add) must include semantic labels and tooltips to preserve accessibility and discoverability.
