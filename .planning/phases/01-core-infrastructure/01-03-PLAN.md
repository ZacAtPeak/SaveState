<objective>
Create the WikiSearchService for in-memory full-text search with title-prioritized relevance scoring.

Purpose: Users need to find wiki pages quickly by typing search queries. The search service maintains an in-memory index of pages and returns results ranked by relevance, with title matches weighted higher than body matches. This is a pure in-memory service — it receives pages from the storage service and indexes them.

Output: WikiSearchService with index/reindex/search methods, WikiSearchResult type, barrel export updated.

    Create `packages/core/lib/services/wiki_search_service.dart` with:

    1. WikiSearchResult class (immutable, following model conventions):
    ```dart
    class WikiSearchResult {
      final WikiPage page;
      final int score;
      const WikiSearchResult({required this.page, required this.score});
    }
    ```

    2. WikiSearchService class:
    - Private field `_index` as `Map<String, WikiPage>` keyed by page ID
    - Method `void index(List<WikiPage> pages)` — replaces the entire index with the given pages. Clear existing index, then add each page by ID.
    - Method `void addPage(WikiPage page)` — adds or updates a single page in the index
    - Method `void removePage(String pageId)` — removes a page from the index by ID
    - Method `void clear()` — empties the index

    3. Search method `List<WikiSearchResult> search(String query)`:
    - If query is empty or whitespace-only, return all pages with score 0
    - Normalize query: lowercase, trim whitespace
    - Split query into individual words (split on whitespace)
    - For each page in the index, calculate relevance score:
      - Title match: For each query word, if it appears in page.title (case-insensitive), add 10 points per word (per D-09: title matches scored higher)
      - Body match: For each query word, if it appears in page.body (case-insensitive), add 1 point per word
      - Tag match: For each query word, if it appears in any page tag (case-insensitive), add 5 points per tag match
    - Filter out pages with score 0 (no matches)
    - Sort results by score descending
    - Return list of WikiSearchResult objects

    Scoring details:
    - Use `.toLowerCase().contains()` for matching (simple substring match, not regex)
    - A single query word matching both title and body gets both scores (10 + 1 = 11)
    - Multiple query words accumulate: "fire ball" matching title "Fireball" = 10 (fire) + 10 (ball) = 20 if both substrings found

    Update `packages/core/lib/services/services.dart` to export the search service:

    What to avoid:
    - Do NOT use external search libraries (D-11: no external search library needed)

    - Do NOT persist the index — it's rebuilt from storage on app startup (D-10: in-memory)
    - Do NOT add alias-based search — deferred to v2 (per CONTEXT.md deferred ideas)
