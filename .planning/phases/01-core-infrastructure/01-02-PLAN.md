  <name>Task 2: Implement WikiStorageService with save/load/list/delete operations</name>
  <files>packages/core/lib/services/wiki_storage_service.dart</files>
  <action>
    Create `packages/core/lib/services/wiki_storage_service.dart` with the WikiStorageService class.

    Constructor:
    - Accept a `Directory baseDirectory` parameter — the root directory where wiki pages will be stored
    - Create a `_pagesDir` getter that returns `Directory('${baseDirectory.path}/wiki/pages')`
    - In constructor, call `_ensureDirectory()` to create the pages directory if it doesn't exist

    Private method `_ensureDirectory()`:
    - Use `Directory` from dart:io to create the pages directory recursively: `_pagesDir.create(recursive: true)`

    Method `Future<void> savePage(WikiPage page)`:
    - Create file path: `File('${_pagesDir.path}/${page.id}.json')` (per D-06: one JSON file per page, named by UUID)
    - Serialize page to JSON: `jsonEncode(page.toJson())`
    - Write file: `file.writeAsString(jsonString)`
    - Import `dart:convert` for jsonEncode, `dart:io` for File/Directory

    Method `Future<WikiPage?> loadPage(String pageId)`:
    - Construct file path: `File('${_pagesDir.path}/$pageId.json')`
    - Check if file exists: `file.exists()`
    - If not exists, return null
    - Read file content: `file.readAsString()`
    - Parse JSON: `jsonDecode(content) as Map<String, dynamic>`
    - Return `WikiPage.fromJson(jsonMap)`

    Method `Future<List<WikiPage>> loadAllPages()`:
    - List all files in `_pagesDir`: `_pagesDir.list()`
    - Filter for .json files only
    - For each file, read and parse into WikiPage (reuse loadPage logic or inline)
    - Handle malformed files gracefully: wrap each parse in try/catch, skip files that fail to parse (agent's discretion per CONTEXT.md — existing models have no error handling, but for a storage service reading from disk, skipping corrupted files is safer than crashing)
    - Return list of successfully loaded pages

    Method `Future<void> deletePage(String pageId)`:
    - Construct file path: `File('${_pagesDir.path}/$pageId.json')`
    - Check if file exists
    - If exists, delete: `file.delete()`

    Import structure:
    ```dart
    import 'dart:convert';
    import 'dart:io';
    import 'package:path/path.dart' as path;
    import 'package:core/models/models.dart';
    ```

    Use the `path` package for constructing file paths: `path.join(_pagesDir.path, '$pageId.json')` instead of string interpolation.

    What to avoid:
    - Do NOT create an abstract interface — the service is concrete and sufficient for v1.
    - Do NOT add edit/update operations — this milestone is create-only (per CONTEXT.md deferred ideas).
    - Do NOT use path_provider — the base directory is injected by the app layer.
    - Do NOT store all pages in a single JSON file — one file per page (D-06).
  </action>
