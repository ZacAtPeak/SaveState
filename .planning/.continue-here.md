<decisions_made>

- **Replace all typed D&D models**: PlayerCharacter/Monster/NPC/WikiPageType enum → GameEntity + runtime registry. No bridge/compat shims.
- **JSON as GameModel format**: Human-readable, importable, matches wiki persistence. No YAML, no Dart-only classes.
- **CoC 7e as proof**: Percentile skills, Sanity, DEX-rank initiative (no roll), no CR/XP/class — proves true agnosticism.
- **No new core dependencies**: rootBundle + provider + dart:convert only. file_picker ^11.0.0 goes in apps, not core.
- **WikiMigrationRunner must precede enum deletion**: loadAllPages() swallows all deserialization errors silently — users lose wiki without migration. This is the single highest data-loss risk.
- **Selector not Consumer**: All downstream GameModelService consumers must use Selector to avoid 5+ widget tree rebuilds on system switch.
- **schemaVersion required from day one**: Cannot be retrofitted. Must be in Phase 5 first commit.
</decisions_made>
